# Bootcamp Repository

## Folder Structure

- **homework/** → All homework contributions will be submitted here.
- **project/** → All project contributions will be submitted here.
- **class_materials/** → Local storage for class materials. Never pushed to GitHub.

## Homework Folder Rules

- Each homework will be in its own subfolder (`homework0`, `homework1`, etc.).
- Each homework folder contains the files required for that assignment, including notebooks, data, source code, and documentation when applicable.
- Homework-specific README documentation is stored inside the corresponding homework folder.

## Project Folder Rules

- Keep project files organized and clearly named.
