# Stakeholder Memo

## Stakeholder

The primary stakeholder is an individual investor who is considering how to allocate money among major U.S. technology stocks.

## Decision

The stakeholder needs to decide which technology stock provides the most attractive balance between historical return and investment risk.

Comparing price growth alone may be misleading because a stock with higher returns may also experience greater volatility or larger drawdowns.

## Key Questions

This project will address the following questions:

- Which stock has generated the strongest historical return?
- Which stock has experienced the highest volatility?
- Which stock has had the largest drawdown?
- Which stock has shown the strongest risk-adjusted performance?

## Proposed Output

The stakeholder will receive a Jupyter notebook containing:

- Historical stock data
- Risk and return metrics
- Comparison tables
- Visualizations
- A short summary of the main findings

## Success Criteria

The project will be successful if the stakeholder can clearly compare the selected stocks using consistent metrics and understand the tradeoff between return and risk before making an allocation decision.

## Key Limitation

The analysis is based mainly on historical market data. It is intended to support investment research rather than predict future returns with certainty or provide financial advice.
