# Stage 12 — Deliverable: `final_report.md`

## Chosen audience

A **non-technical portfolio manager / investment committee** — people who will act on the numbers but do
not want to read code. They need decision-oriented headlines, plain-language assumptions and risks, and a
clear "what this means for you."

## Why this format fits

A single **Markdown report** was chosen because:

- **Text + charts read linearly** — the reader absorbs the executive summary first, then each chart.
- **Self-contained** — charts are exported PNGs in `images/`, so the report renders on GitHub, in a wiki,
  or after conversion to PDF, with no runtime.
- **Skimmable** — a bullet takeaway under each chart gives the decision at a glance.
- **Reproducible** — the exact figures are regenerated by `notebooks/project_pipeline.ipynb`, so a
  technical peer can audit every number.

## Files

- `final_report.md` → the stakeholder-facing deliverable
- `images/*.png` → exported figures
